# Классификация профилей и ассетспейсов по устройству

## Суть

Профили Exocortex и ассетспейсы делятся по **устройству-зависимости** на два типа. Это разделение — фундамент безопасного монтирования новых изолированных контекстов.

| Тип | Описание | Пример |
|---|---|---|
| **Device-agnostic** (устройство-независимый) | Монтирует общий рабочий/личный контекст, нужный на любом устройстве (iPhone, личный ноут, рабочий макбук) | `$$kitelev-tbank`, `$$kitelev-my` |
| **Device-specific** (устройство-специфичный) | Монтирует ассеты, ценные только на конкретном устройстве (локальные ссылки, доступ через корп. сеть) | `$$kitelev-tbank-mac16`, ассетспейс `exoas-tbank-mac16` |

## Критическое правило композиции профилей

**Device-specific профиль должен:**
1. **Импортировать device-agnostic профиль** через `exo__Profile_imports` (например, `$$kitelev-tbank`).
2. **Явно монтировать только device-specific ассетспейсы** через `exo__Profile_includes`.

```yaml
exo__Profile_imports: "[[<device-agnostic-profile-uid>]]"   # весь общий набор
exo__Profile_includes:
  - "[[<device-specific-assetspace-descriptor-uid>]]"        # только device-specific
```

**Почему это критично:** `apply-profile` — это **SWITCH (переключение), а не ADD**. Он приводит файловую систему к *эффективному набору профиля*. Если `_includes` содержит только device-specific AS, а в vault уже смонтировано 20+ ассетспейсов — `apply-profile` **снесёт всё вне замыкания нового профиля** (план покажет `N AS to tear down`). Импорт device-agnostic профиля даёт весь рабочий набор + явные device-specific AS → безопасный план `0 files to remove, 0 AS to tear down`.

## Как определить активный профиль vault

Не предполагать имя (`$$kitelev-tbank-full` и т.п.) — всегда проверять конфиг плагина:

```bash
cat ~/Documents/vaults/vault-tbank/.obsidian/plugins/exocortex/data.local.json
# activeProfileUid → активный профиль
# previousProfileUid → предыдущий (если переключались)
```

## Проверка перед применением (mandatory)

Перед `apply-profile --yes` всегда запускать `apply-profile --verbose` (read-only план):

```bash
exocortex-cli apply-profile <UID> --vault ~/Documents/vaults/vault-tbank --verbose
```

- **Безопасный план:** `0 files to remove, 0 AS to tear down, 1 AS to materialize` (или 0, если уже смонтирован).
- **Опасный план:** `N files to remove` или `M AS to tear down` (M > 0) — НЕ применять, вернуться и добавить `Profile_imports`.
