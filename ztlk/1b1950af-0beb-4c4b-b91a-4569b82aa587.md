Эхоизация книги «300 упражнений для коучинга». При массовом создании ассетов через bulk_gen (exocortex-cli create) бить на партии по ~15 ассетов (PARALLEL=3) и генерировать по одной главе за раз. Пачка целиком (234 ассета одним bulk_gen) или 4 главы параллельно дают массовые таймауты CLI (OK=24 ERR=210). Одиночный exocortex-cli create ~11-18s (переиндексирует vault при каждом вызове). Партия из 15 с PARALLEL=3 ≈ 80-150s, 0 ошибок. Контекст: книга 300 упражнений.
